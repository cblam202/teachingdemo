What am I moving?

The observed input is the sample mean in original units, in either view. The p-value slider finds the statistic with the selected tail area. Typing an observed value calculates its p-value without rounding to the slider steps. Dragging snaps p to steps of 0.01. For a two-tailed test, both tails count.

The red region is set by α. Changing α changes the decision threshold, not the observed p-value. This demo uses p < α to reject H₀ and p ≥ α to fail to reject H₀.

SE = SD / √n and DF = n − 1 are calculated automatically. Changing sample size, null mean, or SD keeps the original observed value fixed. Switching views shows the same test on a different scale.

For Student’s t, use the sample SD. The original-scale curve illustrates mean + t × SE.
